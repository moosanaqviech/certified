Core AWS Services to Know for the Cloud Practitioner (CLF-C02) Exam

The AWS Certified Cloud Practitioner (CLF-C02) exam tests core services at identify-the-right-tool depth: compute (EC2, Lambda, Elastic Beanstalk), storage (S3, EBS, EFS), databases (RDS, DynamoDB), and networking (VPC, Route 53, CloudFront), plus the security, billing, and support services woven through the other domains.

Last updated August 2026.

The depth the exam actually expects

Cloud Technology and Services is the largest CLF-C02 domain at 34% of scored content, about 17 of the 50 scored questions. But the exam guide's task statements are written at an identify-and-describe level, and questions follow them: given a described need, pick the service whose job matches. You will not be asked to size an instance, write an IAM policy, or design a subnet.

That sets the study bar. For every service below, the goal is a one-sentence job description you can produce on sight. If you can also say when a neighbouring service is the better fit (Lambda versus EC2, EFS versus EBS), you are at full exam depth for this domain.

The pairings questions are built on

CLF-C02 service questions are usually a disguised comparison between two plausible services. These are the distinctions worth rehearsing:

  • EC2 versus Lambda: ongoing control over servers versus event-driven code with zero server management. "No infrastructure to manage" in a scenario points at Lambda.
  • EBS versus EFS versus S3: a disk for one instance, a file system for many, objects for everything else. "Accessed by multiple instances simultaneously" is EFS; "store and retrieve any amount of data" is S3.
  • RDS versus DynamoDB: relational with SQL versus key-value at scale. Mentions of joins or existing SQL applications point at RDS; millisecond lookups by key point at DynamoDB.
  • CloudFront versus Route 53: both live at the edge, but one caches and delivers content, the other resolves names. "Reduce latency for global users fetching content" is CloudFront.
  • Regions versus Availability Zones versus edge locations: the geography underneath every service answer. Multi-AZ is high availability inside a region; multi-region is disaster recovery and latency; edge locations belong to CloudFront.

The services hiding in the other domains

Two thirds of the exam is not the services domain, yet still names services. Budget recognition time for these:

  • Security and Compliance (30%): IAM users, groups, roles, and policies, the root user and MFA, and AWS Artifact for compliance reports. The shared responsibility model frames nearly every question here.
  • Billing, Pricing, and Support (12%): AWS Budgets for alerts, Cost Explorer for analysis, the pricing calculator for estimates, consolidated billing through AWS Organizations, and the support plan tiers.
  • Cloud Concepts (24%): lighter on named services, heavier on the Well-Architected Framework pillars and cloud economics, but expect the compute and storage names to appear inside its scenarios.

A service-flashcard plan that stops at Domain 3 leaves the IAM and billing-tools questions, roughly a fifth of the exam, to chance.

FAQ

Which AWS services do I need to know for the Cloud Practitioner exam?

The core set is compute (EC2, Lambda, Elastic Beanstalk), storage (S3, EBS, EFS), databases (RDS, DynamoDB), and networking (VPC, Route 53, CloudFront), plus IAM and AWS Artifact for security and the billing tools: Budgets, Cost Explorer, the pricing calculator, and Organizations. The exam guide lists the full in-scope set.

How deeply does CLF-C02 test each AWS service?

At identify-and-describe depth: given a scenario, pick the service whose job fits. You will not configure, size, or code anything, so the right preparation is a one-line job description per service and the ability to separate close pairs like Lambda versus EC2.

Do I need to memorize every AWS service for the exam?

No. Work from the in-scope services list in the CLF-C02 exam guide rather than the full AWS catalogue. Many listed services only need category-level recognition, while the core compute, storage, database, and networking services carry most of the questions.

What is the most tested topic in the CLF-C02 services domain?

The comparisons: EC2 versus Lambda, the three storage services, RDS versus DynamoDB, and where Regions, Availability Zones, and edge locations fit. Questions are usually a scenario that fits one service noticeably better than its plausible neighbour.

Work from the official in-scope list

The CLF-C02 exam guide names the in-scope services under every task statement, which makes it the definitive flashcard source for this domain.
