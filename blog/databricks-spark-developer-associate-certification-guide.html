Databricks Certified Associate Developer for Apache Spark: The Complete 2026 Guide

The Databricks Certified Associate Developer for Apache Spark exam validates that you can build and tune Spark DataFrame applications in Python. It is a 45-question, 90-minute proctored exam that costs US$200, spans seven officially weighted sections from architecture to the Pandas API on Spark, allows no documentation, and has no published passing score.

Last updated October 2026.

Who the Spark Developer Associate exam is for

The audience is a developer who writes PySpark: data engineers, analytics engineers, and Python developers who load files, shape DataFrames, join and aggregate them, and need to know why a job is slow. The exam is about Apache Spark itself, not about the Databricks workspace, so most of what it tests carries over to Spark on any platform.

There is no required prerequisite. Databricks highly recommends related course attendance and about six months of hands-on Apache Spark experience. That recommendation matters more than usual here, because the exam allows no test aids, including the API documentation. You need to recognize method names, argument orders and defaults from memory, the way you would if you wrote Spark every week.

Two details catch people out. First, 45 is the scored count: unscored questions may also appear, they are not identified, and extra time is factored in for them. Second, Databricks does not publish a cut score. Certify uses 70% as its own practice target on the course exams and in the practice hub, and that is our guidance, not an official threshold.

Many questions are code-reading: a short scenario and four PySpark snippets, where the wrong options use a real method with the wrong argument, the wrong order, the wrong mode, or a method that does not exist. That is why reading code fast matters as much as knowing concepts.

What is different if you learned on older Spark

The exam guide names no Spark version, but on its 30 October 2025 date the current Apache Spark release was 4.0, and the objectives name 4.0-era features. Certify teaches Spark 4.0 behavior as current. If your Spark knowledge comes from 2.x or early 3.x material, these are the points to refresh:

  • Spark Connect has its own section. The decoupled client and server, the thin pyspark-client package, SparkSession.builder.remote("sc://host:15002"), and spark.api.mode (new in Spark 4.0, classic or connect). The client cannot use RDD or SparkContext APIs.
  • Pandas API on Spark, not Koalas. import pyspark.pandas as ps has shipped with PySpark since Spark 3.2. Section 7 also covers Pandas UDFs, the Arrow-backed vectorized form.
  • AQE is on by default (since Spark 3.2). Adaptive Query Execution coalesces shuffle partitions, switches a join to broadcast at runtime and splits skewed partitions, so it is the default answer to many tuning questions.
  • Defaults you must know cold: spark.sql.shuffle.partitions is 200, spark.sql.autoBroadcastJoinThreshold is 10 MB, and cache() on a DataFrame uses MEMORY_AND_DISK.
  • Stateful streaming in Python now centers on transformWithStateInPandas (Spark 4.0), with applyInPandasWithState as the older API.
  • ANSI SQL mode is on by default in Spark 4.0, so an invalid cast raises an error instead of returning null, and Mesos is no longer a supported cluster manager.

How to prepare

  1. Start with the execution model. Jobs, stages and tasks, partitions and shuffles, transformations versus actions. Every tuning and streaming question leans on it.
  2. Write the DataFrame API by hand. Section 3 is 30% and is mostly code reading. Type withColumnRenamed, dropDuplicates, unionByName and join(other, on, how) until the argument order is automatic.
  3. Learn the trade-off pairs. The exam likes "which one": repartition versus coalesce, broadcast hash join versus sort-merge join, append, update and complete output modes, and local, client and cluster deploy modes.
  4. Do not skip the 5% sections. Spark Connect and the Pandas API on Spark have two objectives each and are among the cheapest marks on the paper.
  5. Finish with timed full-length sets. 45 questions in 90 minutes, no docs, until you score comfortably above your target more than once.

FAQ

How many questions are on the Databricks Spark Developer Associate exam?

The exam has 45 scored multiple-choice questions with a 90-minute time limit. Unscored questions may also appear without being identified, with extra time factored in, so the form can show more than 45.

What is the passing score for the Databricks Certified Associate Developer for Apache Spark?

Databricks does not publish a passing score for this exam. Certify uses 70% as its own practice target, but that is guidance, not an official cut score.

Can I use the Spark documentation during the exam?

No. The exam allows no test aids, including API documentation, so you need to recognize PySpark method names, arguments and defaults from memory.

Is the Spark Developer Associate exam in Python or Scala?

All code on the current exam is Python (PySpark). Scala is not shown, and Datasets come up only as the typed Scala and Java form of a DataFrame.

How much does the Databricks Spark Developer Associate exam cost?

Registration is US$200, delivered online with a proctor or at a test center. The certification is valid for two years, after which you take the full live exam again.
