AWS Certified Solutions Architect Associate (SAA-C03): The Complete 2026 Guide

The AWS Certified Solutions Architect Associate (SAA-C03) exam tests whether you can choose the right AWS design for a stated requirement: secure, resilient, high-performing or cost-optimized. It is 65 questions in 130 minutes, costs $150 USD, and needs a scaled score of 720 to pass. SAA-C03 is still the current version in October 2026.

Compensatory scoring means there is no per-domain pass mark. You need one overall scaled score of 720, so a weak domain can be carried by strong ones. The 15 unscored questions are mixed in and not marked, so treat every question as if it counts.

The four domains and their weights

The exam guide anchors SAA-C03 to the AWS Well-Architected Framework. Its four domains are four of the framework's six pillars, which is why so many questions read "which design meets the requirement with the least operational overhead".

Security is the largest domain, and it reaches well beyond IAM: VPC design, security groups and network ACLs, encryption with AWS KMS, and backups all sit in Domain 1. The domains and weighting breakdown walks through all 14 task statements.

What the exam actually rewards

SAA-C03 is a design exam, not a configuration exam. Almost every question gives a scenario with one or two hard requirements and asks which architecture meets them. Three habits separate a pass from a near miss:

  • Find the deciding requirement. "Must survive the loss of an Availability Zone", "with the least operational overhead", "at the lowest cost" and "without changing the application" each rule out options before you weigh the rest.
  • Know the pairs AWS likes to contrast. Security groups vs network ACLs, gateway vs interface VPC endpoints, Secrets Manager vs Parameter Store, SQS vs SNS vs EventBridge, read replicas vs Multi-AZ, Savings Plans vs Reserved Instances.
  • Prefer managed when the scenario says so. When the requirement is minimal operations, the managed or serverless service is usually right, but only because a stated requirement rules out the self-managed one.

Multiple response is the format to practise. A "choose two" question scores nothing unless both selections are right. Each option has to be judged on its own, not as half of a pair.

Services the guide names that AWS has since closed

The SAA-C03 guide has not been revised for some service changes. Several services in its in-scope list are no longer open to new customers, and a current study plan should know which:

  • AWS Snowball Edge is no longer available to new customers. AWS points to AWS DataSync, AWS Data Transfer Terminal and AWS Outposts instead.
  • Amazon Glacier, the original vault-based service, no longer accepts new customers. Archive questions mean the S3 Glacier storage classes and S3 Lifecycle rules.
  • Amazon Elastic Transcoder reached end of support on 13 November 2025.

Learn the replacement first and the old name as background. A question can still mention a closed service as a distractor, so it helps to know why it is no longer the answer.

Who SAA-C03 is for

AWS describes the target candidate as someone with at least one year of hands-on experience designing cloud solutions on AWS. That is a recommendation, not a requirement: there are no prerequisites, and many people take SAA-C03 as their first associate exam.

A good fit if...

You build or review AWS architectures, or you are a developer, sysadmin or data engineer who wants the cross-service design view that every other AWS associate exam assumes.

Start elsewhere if...

AWS itself is new to you. Cloud Practitioner builds the vocabulary first, or plan for the longer timeline below.

How long to prepare

Most candidates with some AWS experience need 6 to 8 weeks of part-time study, roughly 60 to 70 hours. Working architects can often be ready in 3 to 4 weeks, and someone new to AWS should budget 10 to 12. These are our estimates, not AWS figures. The SAA-C03 study plan lays out the weeks, and the cost and format post covers booking, retakes and the question types.

FAQ

Is SAA-C03 still the current AWS Solutions Architect Associate exam in 2026?

Yes. SAA-C03 is the current version as of October 2026, and AWS has not published a successor exam guide. Check the AWS certification page before booking, since AWS announces new versions there first.

How many questions are on the AWS Solutions Architect Associate exam?

65 questions in 130 minutes. Only 50 are scored; the other 15 are unscored trial questions that are not identified during the exam, so answer every question as if it counts.

What is the passing score for SAA-C03?

720 on a scaled score of 100 to 1,000. Scoring is compensatory, so there is no separate pass mark for each domain: a strong result in one domain can make up for a weaker one.

How much does the AWS Solutions Architect Associate exam cost?

$150 USD, the standard AWS associate exam fee. Retakes are paid in full, and the certification is valid for three years.

Do I need Cloud Practitioner before Solutions Architect Associate?

No. AWS has no prerequisites for SAA-C03. Cloud Practitioner helps if AWS is new to you, but candidates with hands-on AWS experience usually go straight to the associate exam.
