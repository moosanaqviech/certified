AWS Certified Cloud Practitioner (CLF-C02): The Complete Certification Guide

CLF-C02 is AWS's foundational certification: 65 questions in 90 minutes, four content domains, and a 700 passing score, with no prerequisites. This guide covers the format, what is tested, who it is for, and how to prepare.

Last updated July 2026.

What CLF-C02 actually is

CLF-C02 is the current version of the AWS Certified Cloud Practitioner exam, the foundational tier of the AWS certification track. It validates a broad understanding of the AWS Cloud, its core services, security and compliance basics, and how billing and pricing work, without requiring you to design or build anything.

There are no required prerequisites. AWS suggests up to six months of general exposure to the AWS Cloud as helpful background, but that is a recommendation, not a gate. It is aimed at people in technical, managerial, sales, purchasing, or finance roles who need working cloud fluency, and it is a common first step before a role-based certification like Solutions Architect Associate.

The four content domains and their weights

The 50 scored questions are spread across four domains. AWS uses a compensatory scoring model, so you pass on your overall scaled score, not domain by domain. Knowing the weights tells you where to invest study time.

Domain 1: Cloud Concepts (24%)

The value proposition of the AWS Cloud, core cloud economics, and design principles. This covers the benefits of cloud (elasticity, agility, economies of scale), the difference between capital and operating expense, the AWS Cloud Adoption Framework at a high level, and the pillars of the Well-Architected Framework. It is concept-heavy rather than service-heavy.

Domain 2: Security and Compliance (30%)

The second-largest domain. It covers the AWS shared responsibility model (what AWS secures versus what you secure), core security and compliance concepts, identity and access management fundamentals (IAM users, groups, roles, and policies, plus the root user and multi-factor authentication), and where to find security and compliance resources such as AWS Artifact. The shared responsibility model shows up repeatedly, so it is worth knowing cold.

Domain 3: Cloud Technology and Services (34%)

The largest domain, and the most service-focused. It covers ways to deploy and operate on AWS, core global infrastructure (Regions, Availability Zones, and edge locations), and the main service categories: compute (EC2, Lambda, Elastic Beanstalk), storage (S3, EBS, EFS), databases (RDS, DynamoDB), networking (VPC, Route 53, CloudFront), and common analytics, integration, and machine learning services at an identify-the-right-tool level. Most of your study hours belong here.

Domain 4: Billing, Pricing, and Support (12%)

The smallest domain. It covers AWS pricing models (on-demand, reserved, spot, savings plans at a conceptual level), billing and cost management tools (AWS Budgets, Cost Explorer, the pricing calculator, and consolidated billing through AWS Organizations), and the AWS support plans and technical resources available at each tier. Twelve percent is roughly six of the 50 scored questions, so it is a fast domain to lock down.

How to prepare

For a foundational exam, a short, structured plan works best:

  • Read the official exam guide first. It lists the task statements and in-scope services for each domain. Questions are written from those statements, so it doubles as a blind-spot checklist.
  • Use the free AWS Skill Builder digital courses. AWS publishes a Cloud Practitioner learning plan and an official practice question set that match the exam's style.
  • Focus on Domains 2 and 3. Together they are 64% of the exam. The shared responsibility model, IAM basics, and the core compute, storage, and database services are where most questions live.
  • Get a little hands-on time. A free-tier account and an hour launching an EC2 instance and an S3 bucket makes the service names stick far better than reading alone.

Candidates with some IT background often prepare in a couple of focused weeks. If AWS is entirely new to you, give the service-heavy Domain 3 the most runway.

Is it worth taking?

Cloud Practitioner will not qualify you for a cloud engineering role on its own. What it does is establish credible baseline AWS fluency, which is genuinely useful for non-engineering roles that touch the cloud and as a confidence check before committing to an associate-level path. With no prerequisites, a modest fee, and broad industry recognition, it is a reasonable first certification for most people entering the AWS ecosystem. Note that, unlike Microsoft's fundamentals certifications, AWS certifications are valid for three years and then require recertification.

FAQ

How many questions are on the CLF-C02 exam?

The exam has 65 questions in total: 50 scored and 15 unscored. The unscored questions are not identified during the exam and do not affect your score.

What score do I need to pass?

The minimum passing score is 700 on a scale of 100 to 1,000. AWS uses a compensatory scoring model, so you do not need to pass each domain individually.

How much does the AWS Cloud Practitioner exam cost?

The exam is $100 USD, before any applicable taxes. AWS also offers local-currency pricing in several regions.

Do I need experience or prerequisites?

No. There are no required prerequisites. AWS recommends up to six months of general AWS Cloud exposure as helpful background, but it is not required to sit the exam.

How long is the certification valid?

AWS certifications, including Cloud Practitioner, are valid for three years. You recertify by passing the current version of the exam or meeting AWS's recertification requirements before it expires.
