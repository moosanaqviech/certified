AZ-900 vs AWS Cloud Practitioner: which cloud fundamentals cert?

Microsoft Azure Fundamentals (AZ-900) and AWS Certified Cloud Practitioner (CLF-C02) are both entry-level cloud certifications with no prerequisites and a 700 passing score. They test the same kind of knowledge on different clouds, so the right choice is the cloud your employer or target role uses. AZ-900 does not expire; Cloud Practitioner is valid for three years.

What each exam tests

AZ-900: three domains

Describe cloud concepts (25 to 30%), Describe Azure architecture and services (35 to 40%), and Describe Azure management and governance (30 to 35%). The architecture domain carries regions, availability zones, resource groups, subscriptions, and the core compute, networking, storage, and identity services, with Microsoft Entra ID as the identity service. Governance covers cost management, Azure Policy, and resource locks.

CLF-C02: four domains

Cloud Concepts (24%), Security and Compliance (30%), Cloud Technology and Services (34%), and Billing, Pricing, and Support (12%). Security gets its own large domain here, anchored on the shared responsibility model and IAM, while the services domain covers EC2, Lambda, S3, RDS, DynamoDB, VPC and the rest at an identify-the-right-tool level.

The real differences

  • Length. AZ-900 gives 45 minutes of question time; CLF-C02 gives 90 minutes for 65 questions. AZ-900 is the quicker sitting.
  • Renewal. Microsoft fundamentals certifications do not expire. AWS certifications, including Cloud Practitioner, are valid for three years.
  • Emphasis. CLF-C02 puts 30% on security and compliance; AZ-900 puts a third on management and governance.

Difficulty is close enough that it should not drive the decision. Both are recognition exams: read a scenario, pick the concept or service that fits.

Which should you take?

AZ-900 if...

Your organization runs on Microsoft 365 and Azure, you are heading toward a role-based Azure path like Azure Administrator (AZ-104), or you want a credential that never needs renewal.

Cloud Practitioner if...

Your team or target employers build on AWS, you plan to move on to an AWS associate exam such as Data Engineer or Machine Learning Engineer, or you want the AI Practitioner next.

If the cloud is not decided for you, look at the job listings you actually want and count which cloud they name. Taking both is cheap and the concepts transfer, since cloud models, pricing, and shared responsibility work the same way on each; the second one mostly means learning a new set of service names.

FAQ

Is AZ-900 easier than AWS Cloud Practitioner?

They are at the same level: both are entry-level exams with no prerequisites and a 700 passing score. AZ-900 is shorter, with 45 minutes of question time against 90 minutes for CLF-C02, but neither is meaningfully harder than the other.

Should I take AZ-900 or AWS Cloud Practitioner first?

Take the one for the cloud your employer or target role uses. If nothing decides it for you, check which cloud the job listings you want name most often, because the concepts transfer and the second exam is mostly new service names.

Does AZ-900 expire?

No. Microsoft fundamentals certifications, including AZ-900, do not expire. AWS Cloud Practitioner, by contrast, is valid for three years.

How much do AZ-900 and AWS Cloud Practitioner cost?

AZ-900 costs $99 USD in the United States and AWS Cloud Practitioner costs $100 USD. Prices vary by country and tax may be added.
